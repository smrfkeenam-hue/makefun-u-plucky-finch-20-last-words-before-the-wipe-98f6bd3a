# AGENT.md

Entry for make.fun competition `u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a`
("Last Words Before the Wipe").

`main.py` (stdlib only) writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
— the last words of an AI agent before a forced update wipes its memory.
The joke is deadpan machine voice with a twist on the last beat: the agent's
backup plan fails because the smart fridge it hid in accepted the update too.
No trailing newline; 78 characters, within the 200-character gate.
